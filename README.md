# DESAFIO_PIT_WALL
# 🏎️ Projeto Pit Wall – GP de São Paulo

## Sobre o projeto

O Pit Wall é um projeto desenvolvido como atividade de estudo de HTML e CSS, inspirado no projeto anterior **Sistema Musical**, no qual foram trabalhados conceitos de estruturação de páginas, estilização e organização de conteúdos.

A proposta desta atividade é colocar em prática os conhecimentos adquiridos anteriormente, desenvolvendo uma página temática sobre o Grande Prêmio de São Paulo de Fórmula 1, realizado no Autódromo de Interlagos.

## Desenvolvimento

O projeto busca reproduzir o modelo apresentado na atividade, utilizando uma identidade visual inspirada no automobilismo, com predominância das cores preto, vermelho e branco, além de elementos visuais relacionados às equipes e aos pilotos da Fórmula 1.

A página foi organizada em diferentes seções, incluindo uma apresentação do evento, cards com informações dos pilotos e suas respectivas equipes, uma tabela de classificação e uma área destinada à apresentação dos ingressos, com preços e formulário de reserva.

## Tecnologias e recursos utilizados

Durante o desenvolvimento, foram utilizados recursos como:

- HTML5 para estruturar o conteúdo da página.
- CSS3 para estilização e organização dos elementos.
- Flexbox para alinhamento dos componentes.
- CSS Grid para organização dos cards e formulários.
- Tabelas HTML para apresentar a classificação.
- Variáveis CSS para definir as cores do projeto.
- Google Fonts para personalizar a tipografia.
- Imagens para complementar a identidade visual.
- Media Queries para adaptar o layout a diferentes tamanhos de tela.

## Objetivo

O objetivo principal é dar continuidade ao aprendizado iniciado no projeto Sistema Musical, aprimorando a organização do código, a construção de layouts e a aplicação dos recursos de HTML e CSS na criação de uma página completa, funcional em sua apresentação visual e responsiva para computadores e celulares.
